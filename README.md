# またね

友だちとふたりで「行きたいところ・やりたいこと」を登録し合い、会う日と読書会をいっしょに管理するノート（PWA）。

公開URL: https://neitianguang209-oss.github.io/matane/

## できること

- **デザイン**：白基調に朱（会う日・主なボタン）・藍（読書会・夜空）・星の金・虹のライン。アイコンは夜空の虹と星。やった！のときは星と虹の紙ふぶき
- **アイコン**：ふたりそれぞれ好きな写真を何枚でも（1024px のまま保存）。選ぶときに丸に入る所をドラッグ・ピンチ・つまみで合わせられる。入れ替えは「開くたび／1時間ごと／毎日／固定」。右上のふたりのアイコンをタップすると、ふたりのアイコンを大きく見られる。自分の写真は一覧・入れ替え方まで見えるが、相手からは「そのとき出ている1枚」だけ（何枚あるかは内緒）。ホーム画面のアイコンも「夜空の虹／白い空の虹／好きな写真」から選べる（この端末だけ）
- **やりたいことリスト**：「行きたいところ」と「やりたいこと」に分けて登録し合う（追加画面で選ぶ）。季節（春夏秋冬）と期限を付けると、「今がちょうどいい」「いつでも」「季節待ち」に自動で並ぶ。期限が近いものは先頭へ
  - タイトルを打つと場所の候補が出る（OpenStreetMap の Photon。キー不要）。タップで場所が決まり、地図もその場所で開く
  - Googleマップのリンク（共有→コピーした maps.app.goo.gl の短いリンクも）を貼るだけで、店名・位置・市区町村が入る（短いリンクは Edge Function `matane` が開いて読む）
  - 似たものがもう入っていたら教えてくれる（ふたりで同じものを足さないように）
  - 相手が追加したものに ☆（私も！）を押すと「ふたりとも」に。ふたりとも行きたいものだけに絞れる
  - タイトルから絵文字を自動で付ける（カフェ→☕、紅葉→🍁 など。選び直せる）
  - リンク（お店のページ・インスタ）、場所、Googleマップで検索
- **会う日（カレンダー）**：月のカレンダーに会う日・読書会の日。祝日は赤。スワイプで月を移動
  - その日にやることを、やりたいことリストから選ぶ／自由に書く
  - Googleカレンダー・iPhoneのカレンダー（.ics）に追加、LINEで予定を送る
  - 終わった日は「どうだった？」→ チェックしたものが「やったこと」に入る
- **読書会**：月◯回（初期値2回）の目標と今月の回数、次回の本・次々回の本
  - 本は打つだけで候補が出る（タイトル・著者・その組み合わせ・ひらがなでもOK）。本の裏のバーコードでも探せる。国立国会図書館サーチ＋Google Books を同時に引いて、合っている順に並べ直す（文庫を先に、大活字本・海外の版・図書館の手製本は後ろ）
  - 次々回の本は交代制（直前に選んだ人ではないほうの番）
  - 本ごとに3つのコーナー：「メモ」（自由に書けるフリースペース、ひとり1枚）／「付箋」（読みながら思ったこと。読書記録アプリと同じ形：ページ・引用・感情タグ・気づき）／「読書会で学べたこと・新しい視点」（だれの話からか）
  - どれも「🔒 自分だけ」にできる。自分だけの合言葉から鍵を作り（PBKDF2→AES-GCM）、端末の中で暗号にしてから保存するので、相手にもクラウドにも読めない。ほかの端末では合言葉を一度入れれば読める（忘れると開けない）
  - 読書会の当日は、ホーム・予定・本の画面に「今日は読書会！」と「＋学び」が出る
  - 語り終えた本は「これまでの本」の本棚に
- **ホーム**：次に会う日までのカウントダウン、ふりかえり、相手から届いた新着、今月の読書会、今の季節にやりたいこと、🌠流れ星におまかせ（やりたいことリストから1つ選ぶ）。相手がまだ入っていなければ招待カード
- iPhone のキーボードが出ても、下から出る画面（本の追加など）や保存ボタンが隠れない
- 新しい版を公開すると「新しい版になりました → 更新」と出る
- 相手が何か追加すると、開いている画面にすぐ知らせが出る

## 仕組み

- React 18 + htm（CDN / esm.sh、ビルド不要）＋ Supabase（既存プロジェクト `gzayrjlhruhvklsidraw` に相乗り、テーブルは `matane_` 接頭辞）
- ログイン無し。部屋のID（16文字のランダム値）が合言葉。テーブルは公開キーから直接読めないよう閉じてあり、IDを知っている人だけが関数 `matane_pull` / `matane_push_batch` 経由で読み書きできる
- 部屋の中身はすべて `matane_items`（kind = member / wish / plan / book / note（メモ）/ like（☆私も）/ memo（付箋・学べたこと）/ photo（アイコンの写真。1行900KBまで））。行ごとに新しいほうが残る（後勝ち）。削除は印を付けるだけ（写真は消すときに中身も空にする）
- 「自分だけ」の行は `private: true` と `enc`（暗号）だけを持ち、本文の欄は空。相手の画面・通知・新着には出さない
- 「私も」と語りたいことは「いつか×人」「本×人」で1行に決め打ちしているので、ふたりが同時に書いてもぶつからない。付箋は1枚ずつ別の行

| ファイル | 役割 |
|---|---|
| `src/lib/store.js` | 端末保存（IndexedDB）・送信待ち・差分同期・リアルタイム・復元 |
| `src/lib/logic.js` | 季節・期限での並び、読書会の順番と交代、ふりかえり対象（純粋関数。`tests.html` でテスト） |
| `src/lib/dates.js` | 日付・季節・カレンダーの計算 |
| `src/lib/books.js` | 本の検索・表紙さがし |
| `src/lib/share.js` | Googleカレンダー・.ics・LINEの文面 |
| `supabase/schema.sql` | テーブル・関数一式 |

## データを失わないために

- 記録はふたりの端末（IndexedDB）とクラウドの両方にある。電波がないときは端末に保存し、つながったら自動で送る
- クラウドから部屋が消えても、端末に記録が残っていれば自動でクラウドを復元する（端末側を消すことはしない）
- 設定 → バックアップを保存（JSON）／バックアップから戻す
- 週次バックアップ（`C:\Users\ひかる\.claude\backup-supabase.ps1`）が `matane_backup_dump` で全件を書き出す（合言葉は同じフォルダの `matane-backup-token.txt`、DBにはハッシュだけ）

## ローカルで動かす

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

http://localhost:5509 を開く（`serve.ps1 -Port 5510` で別の番号でも起動できる）。ロジックのテストは http://localhost:5509/tests.html（60件）

## 更新するとき

アプリのファイルを直したら、`sw.js` の `CACHE_NAME` の番号を1つ上げてから push する（上げないと古い画面が出続ける）。ファイルを増やしたら `sw.js` の `APP_SHELL` にも足す。

## iPhone に入れる

1. 公開URLを **Safari** で開く
2. 共有ボタン → 「ホーム画面に追加」
